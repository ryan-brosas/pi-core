# Copyhackers Source Map

This map records the public articles, tutorials, and resource pages inspected for the conversion-copywriting skill. The skill and references independently restate useful decisions. They do not reproduce source prose, examples, or structure.

The public sitemap inventory contained 683 post and page URLs when reviewed. WordPress metadata exposed 289 blog posts. The 67 sources below were selected for broad practical coverage. Career advice, product promotion, tool roundups, duplicate beginner posts, thin confirmation pages, and channel tips with little durable copy guidance were excluded.
